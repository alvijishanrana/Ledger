# Dining Management System for University Dorm

## Introduction
The Dining Management System is designed to simplify and enhance the dining experience for students living in university dormitories. This system allows students to manage their meal plans, track food consumption, and provide feedback about food quality and service.

## Features
- **Meal Plan Management**: Students can choose from various meal plans, customize their preferences, and make changes based on dietary needs.
- **Online Ordering**: Students can order meals online, allowing for easy pick-up and delivery options.
- **Feedback System**: A platform for students to provide feedback on meals served, which helps improve food quality and service.
- **Reports and Analytics**: Admins can access reports on food consumption, popular dishes, and student preferences to optimize menu offerings.

## Technologies Used
- **Frontend**: HTML, CSS, JavaScript, React
- **Backend**: Node.js, Express
- **Database**: MongoDB

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/alvijishanrana/Ledger.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Ledger
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```

## Usage
- After starting the application, navigate to `http://localhost:3000` in your browser.
- Users will need to sign up or log in to access the dining management features.
