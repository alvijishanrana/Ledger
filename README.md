# Shared Expense Management System

This project aims to simplify the management of shared expenses among friends, families, or groups. It allows users to input, track, and manage their shared expenses effortlessly. Users can:

- Add new expenses
- View a summary of shared costs
- Split expenses evenly or by custom amounts
- Generate reports for accountability and clarity

## Features
- User-friendly interface
- Real-time updates
- Define various groups for specific expense tracking
- Notifications for pending dues and payments

## Getting Started
- Clone the repository
- Install the necessary dependencies using the provided package manager
- Run the application and start managing your shared expenses effectively!
